# @gnomon-ui/theme

Optional calibration-lab design tokens for Gnomon UI examples.

```bash
pnpm add @gnomon-ui/theme@next
```

```ts
import "@gnomon-ui/theme/styles.css";
```

The stylesheet exposes mineral, ink, cobalt, acid, hairline, radius, and motion
tokens. Gnomon primitives are headless; the theme is optional and can be replaced
by project-owned CSS.

This is an alpha release. See the
[Gnomon UI site](https://ray0907.github.io/gnomon-ui/) and
[source](https://github.com/Ray0907/gnomon-ui).
