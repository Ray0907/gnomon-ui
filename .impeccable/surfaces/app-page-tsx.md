# Homepage Surface Brief

- **Scope and mode:** `app/page.tsx`; Persuade with an embedded Operate demo.
- **Audience:** Frontend engineers and design engineers evaluating whether Gnomon
  UI can support a real spatial collection without taking over rendering.
- **Job:** Understand the primitive model, interact with it, compare React and Vue,
  and copy the install command.
- **Primary action:** Open documentation; secondary action is copying installation.
- **Proof:** One shared selection state visibly connects component anatomy, DOM
  controls, code, and the live Three.js object.
- **Constraints:** Static export, procedural/synthetic assets, accessible fallback,
  mobile reading order, no framework lock-in, no unverified performance claims.
- **Direction:** Split docs + live demo in a calibration-lab visual system.
- **Memorable moment:** A registration line joins `Spatial.Item` to the selected
  object while `data-state` and the framework code update together.
- **Unresolved:** Final public package namespace availability and production URL.
